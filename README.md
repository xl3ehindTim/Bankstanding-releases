# Bankstanding

Een OSRS-geïnspireerde idle desktopgame voor Windows.

## Downloaden

[Download de nieuwste versie](https://github.com/xl3ehindTim/Bankstanding-releases/releases/latest).
Kies **Bankstanding-Setup-VERSIE.exe** en voer de setup één keer uit. Daarna downloadt de game nieuwe releases op de achtergrond. Klik op **Herstart om bij te werken** wanneer het jou uitkomt.

Gebruik je nog een oude ZIP of portable? Sluit die eerst af en installeer de setup. Je bestaande voortgang op dezelfde Windows-gebruiker blijft behouden. Stuur saves niet mee naar vrienden: iedereen krijgt zijn eigen voortgang.

Deze repository bevat openbare downloads en release notes. De broncode staat elders. De Windows-installer is nog niet code-ondertekend.

Bankstanding is een onafhankelijk fanproject, niet verbonden aan of goedgekeurd door Jagex. RuneScape en gebruikte OSRS-assets behoren toe aan Jagex.
